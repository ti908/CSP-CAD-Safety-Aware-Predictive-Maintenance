## Use in This Research

The dataset is used to evaluate machine-failure prediction,
probability calibration, conformal prediction, and cost-aware
selective decision-making.

The AI4I dataset is synthetic and represents simulated
industrial machine operating conditions.

The dataset file is retained in its original CSV form for
this research. The research pipeline performs preprocessing
and feature transformations during model development.
